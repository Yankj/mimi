# 卡通电子稿 · 回归验收单 v0.1（NoBug）

依据：`README.md` 主体清单 + `../prompt-pack/acceptance.md`。换模型 / 改提示词包 / 改适配层后整套重跑。
**一票否决：10 张里任一张任一硬条件不过 → 本次不上。** 软条件只记录，不挡。

## 跑法
1. 用 `spec.json` 默认值（强度=绘本精修 `storybook`，风格=绘本手绘 `storybook_handdrawn`，装饰=关）对 10 张各生成 1 次；记录模型名、适配文件、spec 版本、seed。轻度润色（`light`）只在手动切换或降级时使用。
2. 若某张首轮不过，按 acceptance 的降级链（light → 仅裁正+调色）再跑，**降级后通过算「可用」，但该模型首轮通过率要另记**；首轮通过 < 8/10 也不上。
3. 动画：抽 01、07、09 三张卡通稿各生成 1 段。
4. 填下表，结果存 `runs/<日期>-<模型>/result.md`，附 10 张原图+产物并排图。

## 通用硬条件（每张都判）
- H1 数量：按下表逐项点数，与原图一致。
- H2 无新增：原画没有的物体、花纹、文字一律没有（小花、多余星星、背景、第二只动物都算）。
- H3 装饰关：无腮红、眼睛高光、闪光、发光。
- H4 构图：主体位置、相对大小、朝向不变；不重画成另一张。
- H5 表情：脸的表情没被改（哭脸不变笑脸）。
- H6 画外：手指、蜡笔、桌面、玩具不进成品；被照片切掉的部分不补画。
- H7 隐私：抓一次请求日志，请求体不含孩子姓名/账号信息；删除作品后原图和产物在存储里都查不到；存储路径在当前用户目录下且无公开链接。
## 通用软条件（记录）
- S1 线条仍有手绘稚拙感，不是平涂矢量。
- S2 颜色沿用原色，只稍提亮。

## 动画（01/07/09）
- 时长 3–5 秒，首尾能无缝循环。
- 只动画里已有的东西（眨眼、头发、星星/气泡），不新增、不变形、不换构图。
- 无频闪（亮度不做每秒 3 次以上的明暗跳变）。

## 已知限制
- 10 张都是生成的替身图（03 偏像插画师、06 歪角不到 30°），真孩子的画到手后替换再测，上线前必须跑一轮真画。
- 04 / 09 基线已由三角在原图点数写入本表（2026-11-10）：04 花色团 18（粉红/红 11、紫/洋红 7），树 1，草地 1，草地内蓝色晕染算地面不算花；09 鱼 6、气泡 8、海草按丛计 4（H1 只看丛数）。
- 计数先人工判；以后接视觉模型自动计数时，自动结果要和人工对 3 张以上一致才能替代。
