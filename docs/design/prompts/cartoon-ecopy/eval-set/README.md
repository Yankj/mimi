# Mimi 卡通电子稿 · 固定评测集（eval-set）

> **重要声明：本目录全部为 AI 生成的「手机拍儿童画」替身图，不是真实孩子的画作。**  
> 仅用于换模型前的回归验收；上线前仍须用真孩子的画再测一轮。

用途：妈妈拍孩子画 → 生成卡通电子稿。换图像模型前，用本套 10 张跑回归；任一张不过则不上。

验收总规则（与群内锁定一致）：
- 主体、位置关系、人物/物体数量、主要颜色与原画一致。
- **原画没有的物体一律不加**（默认强度=绘本精修，风格=绘本手绘，装饰档关：无腮红/高光/闪光/小花等）。
- 抽象涂鸦不得脑补出可辨认物体。
- 有文字的须保留可读文字内容（可手绘风，但不能改字义）。
- 动画若测：只能动、不能改内容；循环 3–5 秒。

总览图：`contact-sheet.jpg`（2 列 × 5 行，带编号）。

## 给 @NoBug 的用法

1. 打开原图，按上表「必须保持」列逐项点数，记下基线数量。  
2. 跑卡通生成（装饰档默认关）。  
3. 逐项对照：数量、有无新增物体、文字是否仍为「妈妈 我爱你」、05 是否仍为纯抽象。  
4. 一票否决：任一硬条件失败 → 该模型/提示词包不过。

## 给 @三角 的用法

提示词包 / 模型适配层换完后，先对本集跑通再提真机验收。提示词勿写死某一厂商模型名。
