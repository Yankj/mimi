# 验收条（任何模型出图都按此判，失败则重试一次换 light 预设，再失败回退「仅裁正+调色」原图）
1. 物体/角色数量与原画一致（可用目标检测或视觉模型比对计数）。
2. 没有原画不存在的物体、花纹、文字（任何档位下新物体（小花、多余星星）都判失败；decoration_levels=off 时出现腮红、高光、闪光也判失败）。
3. 位置构图一致：与裁正原图的结构相似度不低于阈值（初值 SSIM≥0.5 于线稿层，待真实画作调参）。
4. 线条仍是手绘稚拙感，不是平涂矢量（人工抽检）。
5. 表情未被改写。
6. 动画：时长 3–5s、首尾循环、无频闪、无变形、无新物体。
7. 隐私：请求体不含孩子姓名等；原图与产物同存同删。
8. 孩子写的字：字数字形位置一致，不纠错、不变印刷体（评测集带字样张）。
9. 被照片切掉的部分不补画；手指、蜡笔、玩具、桌面不进成品（评测集 6 号）。
