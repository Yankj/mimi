# 小咪能力全景可执行清单（2026-10-29）

来源是当日定稿的产品全景，不另起一套定位。实时交付与验收状态仍只在[主计划](../status/master-plan.md)。本清单是三层对照：**已有 / 缺口 / 本小时任务**。它不是验收通过声明，也不授权合 main、部署或真机重装。

## 定位

小咪是给宝妈用的「**今天安排 + 成长留痕**」育儿壳，不是聊天机器人、不是办公 Agent。

- **承诺：** 自然语言/语音 → 确认卡 → 点头后才进本机账本。
- **主航道：** 今天 | 成长 | 我们家。聊天只服务整理，不抢主入口。
- **隐私：** 本机规则优先；冲突/低置信才上模型（脱敏）；档案本机结构化，确认后才长期；只有点「让小咪整理」才发原话。

## 本小时自测：档案确认后才落长期事实

合成规则，不代替真机。Xcode 里跑 `ParentingProfileTests` 与 `ParentingNaturalInputTests` 中带 `Archive` / `LongTerm` / `LowConfidence` 的用例。

手动路径（本机，不点「让小咪整理」，不发云）：

1. 只有一个孩子时说「记入档案对花生过敏」。确认卡应写出这个孩子和事实。点「先不记」后，我们家看不到这条长期事实。
2. 点「确认记入档案」后，孩子档案页出现「长期事实」。账本里这条是已确认，来源是确认卡。
3. 两个孩子、没说昵称，或只说「老大/二宝」：不出可写入的确认卡，账本不增加长期事实。认娃点选不在这条路径。
4. 「记在我们家周三奶奶接园」确认后，出现在我们家的家庭长期事实，不进今天的安排。
5. 「团团周五下午5点游泳」仍是安排确认卡，不进档案。
